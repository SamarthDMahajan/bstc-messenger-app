# BSTC Messenger UI Library

A modular, TypeScript-based UI component library built for the BSTC Messenger application.
Developed using React, Storybook, and CSS Modules.

## 🚀 Getting Started

Run the Storybook environment to view and interact with components:

```bash
npm run storybook
```

## 📦 Components

| Component | Status | Description |
| :--- | :--- | :--- |
| **Button** | ✅ Ready | Supports variants (primary, secondary), sizes, and loading states. |
| **Input** | ✅ Ready | Text fields with labels, error states, and helper text. |
| **Modal** | ✅ Ready | Accessible dialogs with backdrop and animations. |
| **Checkbox** | ✅ Ready | Custom styled checkboxes with keyboard support. |
| **Dropdown** | ✅ Ready | Select menus with click-outside closing logic. |
| **Loader** | ✅ Ready | Scalable CSS spinners for loading states. |
| **Radio** | ✅ Ready | Single selection radio buttons. |

## 🛠 Tech Stack
- **React 18**
- **TypeScript** (Strict Typing)
- **Storybook**
- **CSS3** (Variables & Flexbox)

## 🎨 Design System Variables
Common colors used across the library:
- Primary Blue: `#007bff`
- Error Red: `#dc3545`
- Text Grey: `#6c757d`
